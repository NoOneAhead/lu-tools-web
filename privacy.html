Privacy Policy

Last updated: November 21, 2026

This Privacy Policy covers the Lu Tools Web Suite (nooneahead.github.io/lu-tools-web) and the SiteSignal Browser Extension (Microsoft Edge / Chrome).

1. Data We Do Not Collect

We do not collect, store, sell, or transmit your browsing history, personal identity, cookies, passwords, or form inputs to any developer-controlled server.

2. How Tool Lookups Work

  • DNS & Security Checks: Domain hostnames you explicitly inspect are queried directly from your browser to public DNS-over-HTTPS resolvers (dns.google) or public endpoints on the target domain (/llms.txt, /robots.txt, /.well-known/security.txt).
  • OSS Dependency Checks: Package names you submit are queried directly against public APIs (api.osv.dev, registry.npmjs.org, pypi.org).
  • Optional Pro License Verification: If you choose to enter a Pro license key inside the SiteSignal extension, the extension verifies that key with Gumroad's license API and stores your unlock status locally using chrome.storage.local.

3. Contact

Questions or privacy requests can be opened via our public GitHub repository: github.com/NoOneAhead/apify-b2b-and-agent-workflows.
